# Video Search App

## 概要
OMDb APIを利用して、タイトルや公開年で映画・ドラマを検索し、詳細情報を表示します。お気に入り機能もあり、ユーザーは気に入った作品を保存できます。また、JWT認証を実装しており、ユーザーはアカウントを作成してログインすることができます。

## 機能
- 外部APIからデータを取得して検索結果・詳細情報を表示
- JWT認証によるログイン機能
- ユーザーごとのお気に入りデータの管理（追加・取得・削除）

## デモ
Renderの無料プランを利用しているため、初回アクセス時は起動に時間が掛かる場合があります。
https://video-search-app-kvjj.onrender.com/

## 使用技術

**フロントエンド**
- React
- React Router
- Vite

**バックエンド**
- Go
- SQLite

**外部API**
- [OMDb API](https://www.omdbapi.com/)

## 工夫した点
- 表示に必要な情報を全てDBに保存するのではなく、必要最小限の情報だけを保存し、その他の情報は外部APIから取得することで、DBの肥大化を防いだ。
- JWT認証を実装して、ユーザーごとにお気に入りを管理可能にした。
- クライアント側でトークンの有無のみでログイン状態を判断するのではなく、サーバー側でJWTの検証を行うことで、認証の正当性を担保した。
- 非同期処理において、APIレスポンスの不整合やネットワークエラーを想定し、try-catchを用いてエラーハンドリングを行うことで、アプリケーションの安定性を意識した。
- 作りかけのフロントエンド中心のコードを読解した上でバックエンドを新規に実装し、アプリケーション全体を再構築した。

## セットアップ

### 必要なもの

- Node.js
- Go 1.25以上
- OMDb APIキー（[こちら](https://www.omdbapi.com/apikey.aspx)から無料取得可能）

### フロントエンド

```bash
npm install
```

```bash
npm run dev
```

### バックエンド
環境変数を設定
```bash
OMDB_API_KEY=your_api_key JWT_SECRET=your_secret_key go run main.go
```
